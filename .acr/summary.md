# AWM (Agent Workflow Model)

The intent faculty in the heybeaux stack — a predictive execution protocol for agent pipelines. Validation domain: equity trading signal generation across ~40 tickers with regime-gated portfolio execution. The signal runner is a cron-managed walk-forward training + scoring pipeline; the resulting model + execution patterns generalize to other intent-driven agent workflows. AWM partners with Lattice on intent-driven gating in the Sonder fencing architecture.

**Provides:** intent-faculty, workflow-model, signal-generation
**Repo:** https://github.com/heybeaux/awm
**Relates to:** intent faculty in Sonder; partners with Lattice on gate policy
